## 反射的作用：

- 反射在啊类加载的时候动态的获取相关的信息
- 可以通过操作字节码的方式来创建一个类的实例
- 可以在不写**new关键字**的情况下来创建实例，使用程序的耦合度降低

## 一、什么是反射？

**反射（Reflection）** 是 Java 提供的一种能力：在运行时动态获取类的信息（如类名、方法、字段等），并可以操作类或对象的行为。它使得程序可以在运行期间了解自己，并调用其内部的方法或构造对象。

---

## 二、反射的使用步骤（详细说明）

### 第一步：获取 Class 对象（字节码对象）

这是反射的第一步，**必须先获取目标类的** `Class` **对象**。有三种常见方式：

#### 方式一：通过类的全限定名

```java
Class<?> clazz = Class.forName("com.example.MyClass");
```

- 常用于配置文件中加载类；
- 类必须存在，否则会抛出 `ClassNotFoundException`。

#### 方式二：通过类的 `.class` 属性

```java
Class<String> clazz = String.class;
```

- 适用于已知具体类的情况；
- 不会触发类的初始化。

#### 方式三：通过对象的 `getClass()` 方法

```java
String str = "hello";
Class<? extends String> clazz = str.getClass();
```

- 适用于已有对象的情况下；
- 会触发类的初始化（如果还没初始化过）。

---

### 第二步：创建类的实例

有了 `Class` 对象后，就可以创建该类的对象：

#### 使用无参构造函数创建实例：

```java
Object obj = clazz.newInstance(); // Java 9+ 已废弃
```

推荐写法（更安全）：

```java
Object obj = clazz.getDeclaredConstructor().newInstance();
```

---

### 第三步：访问类中的成员（方法、属性等）

#### 获取类的所有方法：

```java
Method[] methods = clazz.getMethods(); // 获取 public 方法（包括继承的）
Method[] declaredMethods = clazz.getDeclaredMethods(); // 获取本类所有方法（不包括继承）
```

#### 调用某个方法：

```java
Method method = clazz.getMethod("sayHello", String.class);
method.invoke(obj, "world"); // 调用 sayHello 方法
```

#### 获取类的字段（Field）：

```java
Field field = clazz.getDeclaredField("name"); // 获取私有字段
field.setAccessible(true); // 如果是 private，需要设置为可访问
field.set(obj, "Tom"); // 设置值
Object value = field.get(obj); // 获取值
```

## 三、反射常用 API 总结

|  |  |
| --- | --- |
| **操作** | **方法** |
| 获取 Class 对象 | `Class.forName("全类名")`  , `类.class`  , `对象.getClass()` |
| 创建实例 | `clazz.getDeclaredConstructor().newInstance()` |
| 获取方法 | `clazz.getMethod("方法名", 参数类型)` |
| 调用方法 | `method.invoke(对象, 参数值)` |
| 获取字段 | `clazz.getDeclaredField("字段名")` |
| 设置字段可访问 | `field.setAccessible(true)` |
| 设置字段值 | `field.set(对象, 值)` |
| 获取字段值 | `field.get(对象)` |

## 四、反射的典型应用场景

1. **Spring 框架底层实现**

- Bean 的创建、依赖注入、AOP 等都依赖于反射。

2. **JDBC 加载驱动**

```java
Class.forName("com.mysql.cj.jdbc.Driver");
```

3. **通用工具类开发**

- 如 Map 和 JavaBean 之间的转换、JSON 解析等。

4. **动态代理**

- Java 动态代理、CGLIB 都使用了反射机制。

---

## 五、反射的缺点（注意点）

|  |  |
| --- | --- |
| **缺点** | **说明** |
| **性能较低** | 反射比直接调用方法慢很多，频繁使用会影响性能 |
| **破坏封装性** | 可以访问私有方法/字段，可能带来安全隐患 |
| **代码复杂度高** | 容易写出难以维护的代码，需谨慎使用 |

## 六、简单示例

```java
public class ReflectDemo {
    public static void main(String[] args) throws Exception {
        // 1. 获取 Class 对象
        Class<?> clazz = Class.forName("com.example.Person");

        // 2. 创建实例
        Object person = clazz.getDeclaredConstructor().newInstance();

        // 3. 获取方法并调用
        Method method = clazz.getMethod("setName", String.class);
        method.invoke(person, "Tom");

        // 4. 获取字段并读取值
        Field field = clazz.getDeclaredField("name");
        field.setAccessible(true);
        System.out.println(field.get(person)); // 输出 Tom
    }
}
```

反射的使用步骤（标准表述）

1. **获取类的 Class 对象（字节码对象）**，有以下三种方式：

- `Class.forName("全限定类名")`：常用于配置文件加载类；
- `类名.class`：适用于静态类或已知类的情况；
- `对象.getClass()`：适用于已有对象的情况。

2. **通过 Class 对象创建类的实例**：

- 使用 `clazz.getDeclaredConstructor().newInstance()` 创建对象。

3. **通过 Class 对象访问类的成员信息**：

- 获取方法、字段、构造器等；
- 调用方法、修改字段值等操作。
