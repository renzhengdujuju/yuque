## 一、什么是注解？

**注解（Annotation）** 是 Java 从 **JDK 5 开始引入** 的一种语法机制，它可以为代码中的类、方法、字段等元素添加元数据信息。

### ✅ 特点：

- 不会影响程序逻辑；
- 可以被编译器或框架读取和处理；
- 常用于替代 XML 配置（如 Spring、Hibernate 等框架中广泛使用）；
- 支持运行时动态解析（通过反射）。

---

## 📦 二、Java 内置注解

Java 提供了一些标准注解，常见的有：

|  |  |
| --- | --- |
| **注解** | **说明** |
| `@Override` | 表示该方法是重写父类的方法 |
| `@Deprecated` | 表示该类/方法已过时，不推荐使用 |
| `@SuppressWarnings("warnings")` | 忽略编译器警告 |
| `@FunctionalInterface` | 标记一个接口为函数式接口（Java 8+） |
| `@SafeVarargs` | 用于抑制可变参数相关的警告（Java 7+） |

## 🔬 三、自定义注解的语法

### ✅ 定义一个注解

```java
public @interface MyAnnotation {
}
```

这个注解可以应用在类、方法、字段等地方。

---

### ✅ 添加属性（成员变量）

```java
public @interface MyAnnotation {
    String name();
    int value() default 0; // 可以设置默认值
    String[] tags() default {"default"};
}
```

使用方式：

```java
@MyAnnotation(name = "test", value = 123, tags = {"a", "b"})
public class MyClass {}
```

如果只有一个属性且名为 `value()`，可以直接传值：

```java
@MyAnnotation(value = 123)
// 等价于
@MyAnnotation(123)
```

## ⚙️ 四、元注解（Meta Annotations）

元注解是用来注解其他注解的注解。常见的有：

|  |  |
| --- | --- |
| **元注解** | **说明** |
| `@Retention` | 指定注解的生命周期 |
| `@Target` | 指定注解可以应用的目标类型 |
| `@Documented` | 是否包含在 Javadoc 中 |
| `@Inherited` | 子类是否继承父类上的注解 |
| `@Repeatable` | 是否可以重复使用（Java 8+） |

### 示例：定义一个运行时可用的注解

```java
import java.lang.annotation.*;

@Retention(RetentionPolicy.RUNTIME) // 注解保留到运行时
@Target(ElementType.METHOD)        // 只能用在方法上
@Documented                         // 包含在文档中
public @interface MyRuntimeAnnotation {
    String description() default "No description";
}
```

## 🔍 五、如何获取注解信息（反射）

可以通过反射获取类、方法、字段上的注解信息。

### 示例代码：

```java
import java.lang.annotation.*;
import java.lang.reflect.Method;

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
@interface MyLog {
    String value() default "INFO";
}

class Example {
    @MyLog("User Login")
    public void login() {
        System.out.println("User logged in");
    }
}

public class AnnotationTest {
    public static void main(String[] args) throws Exception {
        Example example = new Example();
        Method method = Example.class.getMethod("login");

        if (method.isAnnotationPresent(MyLog.class)) {
            MyLog log = method.getAnnotation(MyLog.class);
            System.out.println("Log Level: " + log.value());
        }

        method.invoke(example); // 调用方法
    }
}
```

输出：

```plain
Log Level: User Login
User logged in
```

## 🎯 六、常见应用场景

## 🧱 七、自定义注解开发步骤总结

### ✅ 步骤如下：

1. **定义注解**

- 使用 `@interface`
- 设置 `@Retention`, `@Target` 等元注解

2. **在目标代码中使用注解**

- 类、方法、字段等位置

3. **使用反射读取注解**

- 通过 `Class`, `Method`, `Field` 获取注解对象

4. **根据注解执行特定逻辑**

## 💡 八、进阶功能：可重复注解（Java 8+）

Java 8 引入了 `@Repeatable`，允许同一个元素上多次使用相同注解。

### 示例：

```java
Repeatable(Roles.class)
@interface Role {
    String value();
}

@interface Roles {
    Role[] value();
}

@Role("admin")
@Role("user")
class User {
}
```

## 🧠 总结一句话：

Java 注解是一种强大的元编程工具，它通过给代码添加结构化元信息，实现了诸如依赖注入、AOP 编程、自动配置等功能，是现代 Java 框架（如 Spring）的核心技术之一。
