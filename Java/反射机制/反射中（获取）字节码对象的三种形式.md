在 Java 反射机制中，**获取类的字节码对象（即** `Class` **对象）** 是使用反射的第一步。一个常见的误解：我们并不是真正去“创建” `.class` 文件，而是**在运行时获取类的 Class 对象**，这个对象包含了类的结构信息。

---

## 一、获取 Class 对象（字节码对象）的三种方式

### 1. **通过类的全限定名获取（最常用）**

```java
Class<?> clazz = Class.forName("com.example.MyClass");
```

- **说明**：这是最常用的方式，适用于运行时动态加载类。
- **适用场景**：从配置文件、数据库或网络读取类名后加载类。
- **注意**：该方法会触发类的加载和初始化。

---

### 2. **通过类的**`.class`**属性获取**

```java
Class<String> clazz = String.class;
```

- **说明**：直接通过类名访问其 `.class` 属性。
- **适用场景**：在编译期就知道要操作哪个类时使用。
- **优点**：效率高，不会触发类的初始化（除非首次使用该类）。

---

### 3. **通过对象的**`getClass()`**方法获取**

```java
String str = "hello";
Class<? extends String> clazz = str.getClass();
```

- **说明**：已有某个对象的情况下，调用其 `getClass()` 方法获取对应的 Class 对象。
- **注意**：返回的是该对象实际所属类的 Class 对象（可能不是声明类型的 Class）。

---

## 二、三者的区别总结

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **获取方式** | **写法示例** | **是否需要实例** | **是否触发类初始化** | **使用场景** |
| `Class.forName()` | `Class.forName("com.example.MyClass")` | 否 | 是 | 动态加载类（如 Spring、JDBC） |
| `.class` | `String.class` | 否 | 否（除非首次使用） | 编译期已知类的情况 |
| `getClass()` | `str.getClass()` | 是 | 否 | 已有对象，需获取其真实类型 |

---

## 三、补充说明

### 类的加载与初始化：

- `Class.forName()` 默认会触发类的静态代码块执行（即类初始化）；
- 而 `.class` 和 `getClass()` 不会主动触发类的初始化，除非是第一次使用该类。

### 泛型支持：

- `Class<T>` 是泛型写法，可以让编译器检查类型安全；
- 比如：`Class<String>` 表示只能代表 `String` 类型的类对象；
- 如果不确定具体类型，可以用 `Class<?>`。

---

## 四、简单示例演示

```java
public class ReflectTest {
    public static void main(String[] args) throws Exception {
        // 方式一：通过类名字符串获取
        Class<?> c1 = Class.forName("java.util.Date");

        // 方式二：通过类的 .class 属性获取
        Class<String> c2 = String.class;

        // 方式三：通过对象的 getClass() 获取
        Date date = new Date();
        Class<? extends Date> c3 = date.getClass();

        // 输出结果
        System.out.println(c1.getName()); // java.util.Date
        System.out.println(c2.getName()); // java.lang.String
        System.out.println(c3.getName()); // java.util.Date
    }
}
```

# 案例：

```java
package reflect;

import com.eagles.pojo.User;

public class ReflectTest01 {
    public static void main(String[] args) {

        try {
            //创建字节码对象的第一种方式Class.forName("")
            Class<?> aClass = Class.forName("com.eagles.pojo.User");

            //类.class
            Class aClass2 = User.class;

            System.out.println(aClass2);
            System.out.println(aClass);

            //对象.getClass方法
            Class<? extends User> aClass3 = new User().getClass();
            System.out.println(aClass3);

        } catch (ClassNotFoundException e) {
            throw new RuntimeException(e);
        }

    }
}
```

```plain
class com.eagles.pojo.User
class com.eagles.pojo.User
class com.eagles.pojo.User
```
