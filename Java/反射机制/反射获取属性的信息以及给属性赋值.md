在 Java 反射中，不仅可以动态获取类的属性（字段）信息，还可以**读取和修改属性的值**。这对于实现通用工具类、ORM 框架、配置映射等功能非常有用。

---

# 复习类和属性的关系：

在 Java 中，**属性（Field）** 和 **类（Class）** 是面向对象编程中的两个基本概念，它们代表了不同的实体，并且具有不同的用途和特性。下面详细解释这两者的区别：

## 1. 定义与作用

### 类（Class）

- **定义**: 类是创建对象的蓝图或模板。它定义了一组属性和方法，这些属性和方法描述了该类的对象的状态和行为。
- **作用**: 类用于封装数据（通过字段/属性）、行为（通过方法），以及状态（通过构造函数初始化）。类可以包含其他类、接口、枚举等作为其成员。

```java
public class Person {
    // 这里定义了类的属性
    private String name;
    private int age;

    // 构造函数
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 方法
    public void sayHello() {
        System.out.println("Hello, my name is " + name);
    }
}
```

### 属性（Field）

- **定义**: 属性是指类中定义的变量，用于存储对象的状态信息。每个对象都有自己的一组属性值，但属性本身是在类中定义的。
- **作用**: 属性用来表示对象的特征或状态。例如，在 `Person` 类中，`name` 和 `age` 就是属性，它们分别表示一个人的名字和年龄。

```java
private String name;  // 属性
private int age;      // 属性
```

## 

## 2. 声明方式

### 类

- 使用 `class` 关键字声明。
- 可以有访问修饰符（如 `public`, `private`, `protected`, 默认）来控制对其的访问权限。

```java
java public class MyClass { /* ... */ }
```

### 属性

- 在类内部声明，通常使用基本数据类型或引用类型。
- 同样可以有访问修饰符来控制访问权限。

```java
private int count;  // 私有的整型属性
public String description;  // 公有的字符串属性
```

## 3. 生命周期

### 类

- 类本身没有生命周期；它是静态存在的，直到 JVM 卸载它。
- 类加载器负责将类加载到内存中，并在第一次使用时进行初始化。

### 属性

- 每个实例化的对象都有自己的属性副本。
- 当对象被垃圾回收时，它的属性也会被释放。

## 4. 访问控制

### 类

- 可以通过访问修饰符控制是否允许其他类继承或者访问该类。

### 属性

- 可以通过访问修饰符控制对属性的直接访问级别，比如 `private` 表示只能在定义该属性的类内部访问，而 `public` 则允许从任何地方访问。

## 5. 实例化

### 类

- 类不能直接实例化；需要通过 `new` 关键字创建类的一个实例（对象）。

```java
MyClass obj = new MyClass();
```

### 属性

- 属性存在于类的实例中，因此必须先实例化类才能访问其实例属性。

```java
System.out.println(obj.description);  // 访问属性
```

## 总结

- **类** 是一个模板，用来定义对象的结构和行为；
- **属性** 是类的一部分，具体描述了对象的状态或特征；
- 类可以包含多个属性，而属性总是属于某个特定的类；
- 类是抽象的概念，而属性则是具体的变量，用于存储数据。

## ✅ 一、反射获取类的属性信息

Java 中使用 `java.lang.reflect.Field` 类来表示类中的属性（字段）。通过 `Class` 对象可以获取类的所有字段信息。

### 1. 获取字段对象的方法：

|  |  |
| --- | --- |
| **方法** | **描述** |
| `getDeclaredField(String name)` | 获取指定名称的字段（包括 private），不包括继承字段 |
| `getField(String name)` | 获取 public 字段，包括从父类继承来的 public 字段 |
| `getDeclaredFields()` | 获取所有声明的字段（包括 private、protected、default） |
| `getFields()` | 获取所有 public 字段（包括继承的） |

---

## ✅ 二、示例代码：获取字段信息

```java
import java.lang.reflect.Field;

class Person {
    private String name;
    public int age;
}

public class ReflectFieldDemo {
    public static void main(String[] args) throws Exception {
        // 获取 Class 对象
        Class<?> clazz = Class.forName("Person");

        // 创建实例
        Object person = clazz.getDeclaredConstructor().newInstance();

        // 获取所有声明的字段（包括 private）
        Field[] declaredFields = clazz.getDeclaredFields();
        for (Field field : declaredFields) {
            System.out.println("字段名：" + field.getName());
            System.out.println("字段类型：" + field.getType().getName());
            System.out.println("修饰符：" + field.getModifiers());
            System.out.println("--------------------");
        }
    }
}
```

```plain
字段名：name
字段类型：java.lang.String
修饰符：2
--------------------
字段名：age
字段类型：int
修饰符：1
--------------------
```

⚠️ `field.getModifiers()` 返回的是一个整数，需要用 `Modifier.toString()` 转换为可读字符串，如 `"private"`、`"public"` 等。

## ✅ 三、反射给属性赋值

要给属性赋值，需要以下步骤：

### 步骤说明：

1. 获取字段对象（Field）；
2. 如果是私有字段，调用 `setAccessible(true)`；
3. 使用 `field.set(对象, 值)` 给字段赋值；
4. 使用 `field.get(对象)` 获取字段的值。

---

### 示例代码：给属性赋值和取值

```java
import java.lang.reflect.Field;

class User {
    private String username;
    public int id;
}

public class ReflectSetGetField {
    public static void main(String[] args) throws Exception {
        // 获取 Class 对象
        Class<?> clazz = Class.forName("User");

        // 创建实例
        Object user = clazz.getDeclaredConstructor().newInstance();

        // 获取字段对象
        Field usernameField = clazz.getDeclaredField("username");

        // 设置字段可访问（如果是 private）
        usernameField.setAccessible(true);

        // 给字段赋值
        usernameField.set(user, "admin");

        // 获取字段值
        Object value = usernameField.get(user);
        System.out.println("username 的值是：" + value); // 输出 admin

        // 获取 public 字段并赋值
        Field idField = clazz.getField("id");
        idField.set(user, 1001);
        System.out.println("id 的值是：" + idField.get(user)); // 输出 1001
    }
}
```

## ✅ 四、注意事项

|  |  |
| --- | --- |
| **注意事项** | **说明** |
| **字段权限问题** | 如果字段是 `private`  ，必须调用 `setAccessible(true)`  才能访问或修改 |
| **类型匹配问题** | `field.set(obj, value)`  中的 `value`  必须与字段类型兼容，否则会抛出异常 |
| **静态字段处理** | 如果字段是 `static`  的，`field.set(null, value)`  即可 |
| **性能问题** | 反射操作比直接访问字段慢很多，频繁使用时要注意优化或缓存 Field 对象 |

---

## ✅ 五、完整流程总结

|  |  |
| --- | --- |
| **步骤** | **操作** |
| 1. 获取 Class 对象 | `Class.forName("包名.类名")` |
| 2. 创建类的实例 | `clazz.getDeclaredConstructor().newInstance()` |
| 3. 获取字段对象 | `clazz.getDeclaredField("字段名")`  或 `getField()` |
| 4. 设置字段可访问 | `field.setAccessible(true)`  （如果是 private） |
| 5. 给字段赋值 | `field.set(对象, 值)` |
| 6. 获取字段值 | `field.get(对象)` |

# 案例：

            //获取类中的属性
            Field address = aClass.getField("address");

            //获取类的全类名
            String name = aClass.getName();
            System.out.println(name);//com.eagles.pojo.User

            //获取类的简易名
            String name1 = aClass.getSimpleName();
            System.out.println(name1);//User

            String typeName = aClass.getTypeName();
            System.out.println(typeName);//com.eagles.pojo.User

            Field address1 = aClass.getField("address");

## 与其他获取类名方法的区别

|  |  |  |
| --- | --- | --- |
| **方法** | **返回值说明** | **示例** |
| `getName()` | 返回全限定类名（对数组和基本类型有特殊格式） | `java.lang.String` |
| `getSimpleName()` | 返回简单类名（不带包名） | `String`  , `List`  , `MyClass` |
| `getCanonicalName()` | 返回规范名称（适用于嵌套类、数组等） | `java.util.List`  , `com.example.Outer.Inner` |
| `getTypeName()` | 返回类型的完整名称（与源码中写法一致） | `java.lang.String`  , `int`  , `int[]`  , `T extends Object`  （泛型） |

---

## 使用示例

```java
public class TestGetType {
    public static void main(String[] args) {
        // 普通类
        System.out.println("String.class.getTypeName() = " + String.class.getTypeName());

        // 基本类型
        System.out.println("int.class.getTypeName() = " + int.class.getTypeName());

        // 数组类型
        System.out.println("int[].class.getTypeName() = " + int[].class.getTypeName());

        // 匿名类
        Object obj = new Object() {};
        System.out.println("obj.getClass().getTypeName() = " + obj.getClass().getTypeName());

        // 泛型（注意：运行时擦除，这里只是举例）
        System.out.println("List<String>.class.getTypeName() = " + java.util.List.class.getTypeName());
    }
}
```

### 输出结果：

```java
String.class.getTypeName() = java.lang.String
int.class.getTypeName() = int
int[].class.getTypeName() = int[]
obj.getClass().getTypeName() = TestGetType$1
List<String>.class.getTypeName() = java.util.List
```

## ✅ `getTypeName()` 的优势

相比 `getName()` 和 `getSimpleName()`，`getTypeName()` 更加贴近开发者在代码中看到的**实际类型名称**，尤其适用于以下场景：

- 日志输出；
- 异常信息展示；
- 框架调试信息；
- 泛型支持（虽然运行时泛型被擦除，但某些上下文中仍可用）；

---

## 注意事项

- **不能用于**`null`**或未加载的类**；
- **返回值为**`String`**，不是可解析的类型对象**；
- **对数组支持良好**，如 `int[]`、`String[][]` 等都能正确显示；
- **对匿名类返回的名称是编译器生成的名称（如**`Test$1`**）**，不可靠。

---

## ✅ 总结

1. **如何通过反射获取类的字段信息？**

- 使用 `getDeclaredField()` / `getDeclaredFields()` 等方法获取字段对象；
- 可以获取字段名、类型、修饰符等信息。

2. **如何通过反射给字段赋值？**

- 使用 `field.set(obj, value)`；
- 如果字段是 `private`，必须调用 `field.setAccessible(true)`；
- 支持对 `public` 和 `private` 字段进行操作。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **方法名** | **用途** | **是否包含包名** | **是否支持数组/泛型** | **推荐使用场景** |
| `getName()` | 获取 JVM 内部使用的类名 | ✅ | ✅（格式特殊） | 反射、底层框架 |
| `getSimpleName()` | 获取类的简单名称 | ❌ | ❌ | 显示用户界面 |
| `getCanonicalName()` | 获取规范名称 | ✅ | ✅（支持嵌套类） | 编译器相关 |
| `getTypeName()` | 获取源码风格的类型名 | ✅ | ✅（更友好） | 日志、异常、调试 |

# 案例：
```java
package reflect;

import com.eagles.pojo.User;

import java.lang.reflect.Field;

public class ReflectTest03 {
    public static void main(String[] args) {
        try {
            //创建字节码对象
            Class aClass = User.class;

            //创建实例
            Object instance = aClass.newInstance();

            //获取属性字节对象
            Field declaredField = aClass.getDeclaredField("name");
            Field classDeclaredFieldId = aClass.getDeclaredField("id");
            Field classDeclaredFieldAddress = aClass.getDeclaredField("address");

            //打破封装
            declaredField.setAccessible(true);
            classDeclaredFieldId.setAccessible(true);//address 是public类型的不需要打破封装就可以进行设置

            //该方法可以给属性赋值，参数1：当前属性所在类的实例，参数2：具体给属性赋的值
            declaredField.set(instance,"张三");
            classDeclaredFieldId.set(instance,1001);
            classDeclaredFieldAddress.set(instance,"镇江市");

            //过滤
            if (instance instanceof User){
                //强转
                User user = (User) instance;
                System.out.println(user);
            }

        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }
}
```

```plain
User{id=1001, name='张三', address='镇江市', birthday='null'}
```
