在 Java 的反射机制中，`java.lang.reflect` 包提供了丰富的 API 来获取类的结构信息、操作对象、方法、构造器和字段等。下面是一些常用的反射方法及其应用场景的总结。

---

## 一、Class 类中的常用方法

### 1. 获取 Class 对象

- `forName(String className)`：通过类的全限定名获取 `Class` 对象。

```java
Class<?> clazz = Class.forName("java.util.ArrayList");
```

- `.class`**语法**：适用于编译时已知的类。

```java
Class<String> clazz = String.class;
```

- `getClass()`**方法**：通过对象实例获取 `Class` 对象。

```java
String str = "Hello";
Class<?> clazz = str.getClass();
```

### 2. 获取类的基本信息

- `getName()`：返回类的全限定名（包括包名）。

```java
System.out.println(clazz.getName());
```

- `getSimpleName()`：返回不包含包名的类名。

```java
System.out.println(clazz.getSimpleName());
```

- `getCanonicalName()`：返回类的规范名称（对于匿名类可能返回 null）。

```java
System.out.println(clazz.getCanonicalName());
```

- `getTypeName()`：返回类型的完整名称（Java 源码风格）。

```java
System.out.println(clazz.getTypeName());
```

### 3. 获取父类与接口

- `getSuperclass()`：返回该类的直接父类。

```java
Class<?> superClass = clazz.getSuperclass();
```

- `getInterfaces()`：返回该类实现的所有接口。

```java
Class<?>[] interfaces = clazz.getInterfaces();
```

---

## 二、获取构造器

### 1. 获取所有公共构造器

- `getConstructors()`：返回一个包含所有公共构造器的数组。

```java
Constructor<?>[] constructors = clazz.getConstructors();
```

### 2. 获取特定公共构造器

- `getConstructor(Class<?>... parameterTypes)`：根据参数类型获取指定的公共构造器。

```java
Constructor<?> constructor = clazz.getConstructor(String.class);
```

### 3. 获取所有声明的构造器（包括私有）

- `getDeclaredConstructors()`：返回一个包含所有声明的构造器的数组。

```java
Constructor<?>[] declaredConstructors = clazz.getDeclaredConstructors();
```

### 4. 获取特定声明的构造器（包括私有）

- `getDeclaredConstructor(Class<?>... parameterTypes)`：根据参数类型获取指定的声明构造器。

```java
Constructor<?> declaredConstructor = clazz.getDeclaredConstructor(int.class);
```

### 5. 使用构造器创建实例

- `newInstance(Object... initargs)`：使用构造器创建新实例（注意需要处理异常）。

```java
Object obj = constructor.newInstance("paramValue");
```

---

## 三、获取方法

### 1. 获取所有公共方法

- `getMethods()`：返回一个包含所有公共方法（包括从父类继承的方法）的数组。

```java
Method[] methods = clazz.getMethods();
```

### 2. 获取特定公共方法

- `getMethod(String name, Class<?>... parameterTypes)`：根据方法名和参数类型获取指定的公共方法。

```java
Method method = clazz.getMethod("methodName", String.class);
```

### 3. 获取所有声明的方法（包括私有）

- `getDeclaredMethods()`：返回一个包含所有声明的方法（包括私有）的数组。

```java
Method[] declaredMethods = clazz.getDeclaredMethods();
```

### 4. 获取特定声明的方法（包括私有）

- `getDeclaredMethod(String name, Class<?>... parameterTypes)`：根据方法名和参数类型获取指定的声明方法。

```java
Method declaredMethod = clazz.getDeclaredMethod("methodName", int.class);
```

### 5. 调用方法

- `invoke(Object obj, Object... args)`：调用指定对象上的方法（如果方法是私有的，需要先调用 `setAccessible(true)`）。

```java
method.invoke(obj, "paramValue");
```

---

## 四、获取字段

### 1. 获取所有公共字段

- `getFields()`：返回一个包含所有公共字段（包括从父类继承的字段）的数组。

```java
Field[] fields = clazz.getFields();
```

### 2. 获取特定公共字段

- `getField(String name)`：根据字段名获取指定的公共字段。

```java
Field field = clazz.getField("fieldName");
```

### 3. 获取所有声明的字段（包括私有）

- `getDeclaredFields()`：返回一个包含所有声明的字段（包括私有）的数组。

```java
Field[] declaredFields = clazz.getDeclaredFields();
```

### 4. 获取特定声明的字段（包括私有）

- `getDeclaredField(String name)`：根据字段名获取指定的声明字段。

```java
Field declaredField = clazz.getDeclaredField("fieldName");
```

### 5. 设置/获取字段值

- `set(Object obj, Object value)`：为指定对象设置字段值（如果字段是私有的，需要先调用 `setAccessible(true)`）。

```java
field.setAccessible(true);
field.set(obj, "newValue");
```

- `get(Object obj)`：获取指定对象的字段值。

```java
Object value = field.get(obj);
```

## 五、其他常用方法

### 1. 判断类是否为某个类型

- `isInstance(Object obj)`：判断指定对象是否为该类或其子类的实例（类似于 `instanceof`）。

```java
boolean isInstanceOf = clazz.isInstance(obj);
```

### 2. 判断类是否是接口

- `isInterface()`：判断该类是否是一个接口。

```java
boolean isInterface = clazz.isInterface();
```

### 3. 判断类是否是基本类型

- `isPrimitive()`：判断该类是否是基本类型（如 `int`, `boolean` 等）。

```java
boolean isPrimitive = clazz.isPrimitive();
```

### 4. 获取注解

- `getAnnotations()`：返回该类上所有的注解。

```java
Annotation[] annotations = clazz.getAnnotations();
```
