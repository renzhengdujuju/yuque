在 Java 中，反射不仅可以用于获取类的字段信息和操作属性值，还可以用来**获取方法的信息以及动态调用方法**。这对于实现通用工具、框架或插件系统非常有用。下面详细介绍如何使用反射来获取方法信息并调用方法。

---

## ✅ 一、获取方法信息

Java 提供了 `java.lang.reflect.Method` 类来表示类中的方法。通过 `Class` 对象可以获取类的所有方法信息。

### 方法获取方式：

|  |  |
| --- | --- |
| **方法** | **描述** |
| `getMethod(String name, Class<?>... parameterTypes)` | 获取指定名称和参数类型的公共方法（包括继承的方法） |
| `getMethods()` | 获取所有公共方法（包括从父类继承来的公共方法） |
| `getDeclaredMethod(String name, Class<?>... parameterTypes)` | 获取本类中声明的所有方法（包括私有方法），不包括继承的方法 |
| `getDeclaredMethods()` | 获取本类中声明的所有方法 |

---

## ✅ 二、示例代码：获取方法信息

```java
import java.lang.reflect.Method;

class Person {
    private String name;
    public int age;

    public void sayHello() {
        System.out.println("Hello, my name is " + name);
    }

    private String getName() {
        return name;
    }
}

public class ReflectMethodDemo {
    public static void main(String[] args) throws Exception {
        // 获取 Class 对象
        Class<?> clazz = Class.forName("Person");

        // 创建实例
        Object person = clazz.getDeclaredConstructor().newInstance();

        // 获取所有公共方法
        Method[] methods = clazz.getMethods();
        for (Method method : methods) {
            System.out.println("方法名：" + method.getName());
            System.out.println("返回类型：" + method.getReturnType().getName());
            System.out.println("参数类型：");
            for (Class<?> paramType : method.getParameterTypes()) {
                System.out.println(paramType.getName());
            }
            System.out.println("--------------------");
        }

        // 获取特定方法
        Method sayHelloMethod = clazz.getMethod("sayHello");
        Method getNameMethod = clazz.getDeclaredMethod("getName");
        System.out.println("sayHello 返回类型：" + sayHelloMethod.getReturnType().getName());
        System.out.println("getName 返回类型：" + getNameMethod.getReturnType().getName());
    }
}
```

## ✅ 三、调用方法

要调用一个方法，首先需要获取到对应的 `Method` 对象，然后使用 `invoke()` 方法来调用它。

### 调用方法的基本步骤：

1. **获取**`Method`**对象**；
2. **设置可访问性**（如果方法是私有的）；
3. **调用**`method.invoke(对象, 参数...)` 来执行方法。

---

### 示例代码：调用方法

```java
import java.lang.reflect.Method;

class Person {
    private String name = "Tom";
    public int age;

    public void sayHello() {
        System.out.println("Hello, my name is " + name);
    }

    private String getName() {
        return name;
    }
}

public class ReflectInvokeMethod {
    public static void main(String[] args) throws Exception {
        // 获取 Class 对象
        Class<?> clazz = Class.forName("Person");

        // 创建实例
        Object person = clazz.getDeclaredConstructor().newInstance();

        // 获取 sayHello 方法
        Method sayHelloMethod = clazz.getMethod("sayHello");
        sayHelloMethod.invoke(person);  // 调用 sayHello 方法

        // 获取 getName 方法
        Method getNameMethod = clazz.getDeclaredMethod("getName");
        getNameMethod.setAccessible(true);  // 设置私有方法为可访问
        Object result = getNameMethod.invoke(person);  // 调用 getName 方法
        System.out.println("Name: " + result);
    }
}
```

输出结果：

```java
Hello, my name is Tom
Name: Tom
```

## ✅ 四、注意事项

### 1. 访问私有方法

- 如果需要调用私有方法，必须先调用 `setAccessible(true)`，否则会抛出 `IllegalAccessException`。

### 2. 参数匹配

- `getMethod()` 和 `getDeclaredMethod()` 需要提供正确的参数类型列表来精确匹配方法签名。
- `invoke()` 方法也需要传入与方法签名相匹配的实际参数。

### 3. 异常处理

- 反射调用过程中可能会抛出多种异常，如 `NoSuchMethodException`, `IllegalAccessException`, `IllegalArgumentException`, `InvocationTargetException` 等，因此通常需要用 `try-catch` 块进行处理。

### 4. 性能问题

- 反射调用比直接调用方法慢得多，因为它涉及到更多的检查和安全检查。频繁使用时应考虑性能优化或缓存 `Method` 对象。

---

## ✅ 五、完整流程总结

### 1. 获取 `Class` 对象

```java
Class<?> clazz = Class.forName("com.example.MyClass");
```

### 2. 创建类的实例

```java
Object instance = clazz.getDeclaredConstructor().newInstance();
```

### 3. 获取方法对象

```java
// 获取公共方法
Method publicMethod = clazz.getMethod("methodName", ParamType.class);

// 获取私有方法
Method privateMethod = clazz.getDeclaredMethod("methodName", ParamType.class);
privateMethod.setAccessible(true);  // 如果是私有方法
```

### 4. 调用方法

```java
// 调用无参方法
publicMethod.invoke(instance);

// 调用带参方法
Object result = publicMethod.invoke(instance, arg1, arg2);
```
