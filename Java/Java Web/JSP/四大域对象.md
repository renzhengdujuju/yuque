在 JSP（Java Server Pages）中，**四大域对象**（也称为四大作用域对象）是用于在不同页面或组件之间共享数据的对象。它们根据**作用范围和生命周期**不同，分为以下四类：

---

## JSP 四大域对象（作用域）一览表：

|  |  |  |  |
| --- | --- | --- | --- |
| **域对象** | **类型** | **作用范围** | **生命周期** |
| `pageScope` | `javax.servlet.jsp.PageContext` | 当前页面（page） | 页面开始到页面结束 |
| `requestScope` | `javax.servlet.http.HttpServletRequest` | 同一个请求（request） | 请求开始到响应结束 |
| `sessionScope` | `javax.servlet.http.HttpSession` | 同一个会话（session） | 用户打开浏览器到关闭浏览器（或超时） |
| `applicationScope` | `javax.servlet.ServletContext` | 整个 Web 应用（所有用户共享） | 应用启动到应用关闭 |

---

## 1. `pageScope`（页面域）

- **作用范围**：仅限于当前页面。
- **生命周期**：从页面开始处理到页面输出完成。
- **使用方式**：

```plain
<% pageContext.setAttribute("msg", "这是页面域的内容"); %>
${pageScope.msg}
```

- **适用场景**：页面内部变量共享，不希望其他页面访问。

---

## 2. `requestScope`（请求域）

- **作用范围**：同一个请求内的多个页面或 Servlet。（只要地址没有发生变化，就能取到域中的值）
- **生命周期**：一次 HTTP 请求。
- **使用方式**：

```java
// 在 Servlet 或 Controller 中设置
request.setAttribute("user", user);
```

```plain
<!-- 在 JSP 页面中获取 -->
${requestScope.user.name}
```

- **适用场景**：请求转发时的数据共享（如 MVC 模式中 Controller 向 JSP 传值）。

---

## 3. `sessionScope`（会话域）

- **作用范围**：同一个用户会话期间。
- **生命周期**：用户首次访问网站开始，直到会话超时或用户关闭浏览器。
- **使用方式**：

```java
// 在 Servlet 中
HttpSession session = request.getSession();
session.setAttribute("loginUser", user);
```

```plain
<!-- 在 JSP 页面中获取 -->
${sessionScope.loginUser.username}
```

- **适用场景**：用户登录信息、购物车等需要跨页面保留的数据。

---

## 4. `applicationScope`（应用域）

- **作用范围**：整个 Web 应用，所有用户共享。
- **生命周期**：Web 应用启动时创建，应用关闭时销毁。
- **使用方式**：

```java
// 在 Servlet 中
ServletContext application = getServletContext();
application.setAttribute("onlineCount", 100);
```

```plain
<!-- 在 JSP 页面中获取 -->
${applicationScope.onlineCount}
```

- **适用场景**：全局变量、网站配置、在线人数统计等。

---

## 作用域大小排序（从大到小）

```plain
applicationScope > sessionScope > requestScope > pageScope
```

---

## EL 表达式访问域对象的优先级

当使用 `${xxx}` 访问变量时，JSP 引擎会按照以下顺序查找：

1. `pageScope`
2. `requestScope`
3. `sessionScope`
4. `applicationScope`

**建议**：为了提高性能和避免歧义，访问变量时最好明确指定作用域，例如 `${requestScope.user}`。

---

## 示例：四大域对象对比

```plain
<%-- 设置各个域对象 --%>
<% 
    pageContext.setAttribute("msg", "pageScope");
    request.setAttribute("msg", "requestScope");
    session.setAttribute("msg", "sessionScope");
    application.setAttribute("msg", "applicationScope");
%>

<%-- 输出结果 --%>
${pageScope.msg}       <br>  <!-- 输出：pageScope -->
${requestScope.msg}    <br>  <!-- 输出：requestScope -->
${sessionScope.msg}    <br>  <!-- 输出：sessionScope -->
${applicationScope.msg}<br>  <!-- 输出：applicationScope -->

${msg} <br>  <!-- 输出：pageScope（优先级最高） -->
```
