# 案例：

```java
-案例：
-创建一个学生类，包含字段 id、name、age、address
-自定义一个异常类：AgeException （编译时异常）

-创建学生对象，年龄不能为负数
-如果年龄为负数，需要抛出异常对象（AgeException）
```

```plain
package com.eagles.pojo;

    public class Student {
        private int id;
        private String name;
        private int age;
        private String address;

        // 构造方法
        public Student(int id, String name, int age, String address) throws AgeException {
            this.id = id;
            this.name = name;
            setAge(age); // 使用 setter 方法来验证年龄
            this.address = address;
        }

        public Student() {
        }

        // Getter 和 Setter 方法
        public int getId() {
            return id;
        }

        public void setId(int id) {
            this.id = id;
        }

        public String getName() {
            return name;
        }

        public void setName(String name) {
            this.name = name;
        }

        public int getAge() {
            return age;
        }

        public void setAge(int age) throws AgeException {
            if (age < 0) {
                throw new AgeException("年龄不能为负数！");
            }
            this.age = age;
        }

        public String getAddress() {
            return address;
        }

        public void setAddress(String address) {
            this.address = address;
        }

        @Override
        public String toString() {
            return "Student{" +
                    "id=" + id +
                    ", name='" + name + '\'' +
                    ", age=" + age +
                    ", address='" + address + '\'' +
                    '}';
        }
    }
```

```java
package com.eagles.pojo;

public class AgeException extends Exception{
    public AgeException(String message) {
        super(message);
    }
}
```

```java
package com.eagles.pojo;

public class TestStudent {
    public static void main(String[] args) {
        try {
            // 创建学生对象，年龄为正数
            Student student1 = new Student(1, "张三", 20, "北京市");
            System.out.println(student1);

            // 创建学生对象，年龄为负数，会抛出异常
            Student student2 = new Student(2, "李四", -5, "上海市");
            System.out.println(student2);
        } catch (AgeException e) {
            System.out.println("捕获到异常：" + e.getMessage());
        }
    }
}
```
