### 在 Java 中，元注解（Meta-Annotations）是用来注解其他注解的特殊注解。它们提供了对自定义注解的行为进行配置的能力。以下是 Java 提供的几个内置元注解及其详细说明：

### 1. `@Retention`

指定注解保留的时间长度。

- **属性**: `RetentionPolicy`

- `RetentionPolicy.SOURCE`: 注解只保留在源码级别，在编译时会被丢弃。
- `RetentionPolicy.CLASS`: 默认值，注解将被编译器记录在 class 文件中，但在运行时不会加载到 JVM 中（即不会存在于.class文件中）。
- `RetentionPolicy.RUNTIME`: 注解不仅将被编译器记录在class文件中，而且可以在运行时通过反射机制访问。

**示例**:

```java
@Retention(RetentionPolicy.RUNTIME)
public @interface MyAnnotation {
}
```

### 2. `@Target`

指定注解可以应用的目标元素类型。

- **属性**: `ElementType`

- `ElementType.TYPE`: 可以应用于类、接口（包括注解类型）、枚举。
- `ElementType.FIELD`: 可以应用于字段（包括枚举常量）。
- `ElementType.METHOD`: 可以应用于方法。
- `ElementType.PARAMETER`: 可以应用于方法参数。
- `ElementType.CONSTRUCTOR`: 可以应用于构造函数。
- `ElementType.LOCAL_VARIABLE`: 可以应用于局部变量声明。
- `ElementType.ANNOTATION_TYPE`: 可以应用于注解类型本身。
- `ElementType.PACKAGE`: 可以应用于包声明。
- （Java 8+）`ElementType.TYPE_PARAMETER`: 可以应用于泛型参数。
- （Java 8+）`ElementType.TYPE_USE`: 可以应用于任何使用类型的上下文。

**示例**:

```java
@Target(ElementType.METHOD)
public @interface MyMethodAnnotation {
}
```

### 3. `@Documented`

指示某个注解在默认情况下应该包含在生成的文档中（如 Javadoc）。如果一个注解被标记为 `@Documented`，那么这个注解将会出现在用户生成的文档中。

**示例**:

```java
@Documented
public @interface MyDocumentedAnnotation {
}
```

### 4. `@Inherited`

指示某个注解类型可以从超类传递给子类。注意，此行为仅适用于类层次结构，并且不适用于接口或方法等其他类型。

**示例**:

```java
@Inherited
public @interface MyInheritedAnnotation {
}
```

### 5. `@Repeatable`

（从 Java 8 开始引入）允许在同一位置多次使用相同的注解。为了使一个注解可重复使用，你需要定义一个包含该注解的容器注解。

**示例**: 首先定义一个重复使用的注解：

```java
@Repeatable(MyRepeatedAnnotations.class)
public @interface MyRepeatableAnnotation {
    String value();
}
```

然后定义一个容器注解来容纳多个 `MyRepeatableAnnotation` 实例：

```java
public @interface MyRepeatedAnnotations {
    MyRepeatableAnnotation[] value();
}
```

这样就可以在一个地方多次使用 `@MyRepeatableAnnotation`。
