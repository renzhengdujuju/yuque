# 方法的重写

```java
package com.eagles.test;

public class Animal {
    public void eat(){
        System.out.println("所有动物都有吃的特性！！！！");
    }
}
```

```java
package com.eagles.test;

public class Cat extends Animal{

  public void eat(){
      System.out.println("猫喜欢吃鱼！！");
  }
}
```

```java
package com.eagles.test;
  /*
    方法的重写：在继承中，当子类与父类有同名的方法的时候，就构成重写
    方法的重写在什么时候会用到：当父类功能不满足子类需求时，子类可以重写父类的方法（全部逻辑，部分逻辑）
     */
public class Test {
    public static void main(String[] args) {
        //创建子类对象
        Cat cat = new Cat();
        cat.eat();
        //Cat.eat()会默认调取父类的eat方法除非子类写了eat方法将其覆盖掉
    }
}
```

子类继承父类，子类和父类具有同名方法，当父类满足不了子类希求时，子类可以重写父类方法。
