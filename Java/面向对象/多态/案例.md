1.多态在以后开发中的应用

-场景：主人喜欢喂养宠物，在前期比较热衷于喂养宠物猫、宠物狗

到了后期，爱好发生了变化，喜欢喂养蛇和鸟

-通过传统的方式来模拟改场景

-同过多态的方式模拟场景

-主人 主人类Master

-宠物 ：Cat、Bird、Rabbit、Dog

-软件开发的原则：开闭原则→对扩展开放，对修改关闭

-如果在软件开发过程中，中途加入了新的需求，可以选择添加新的模块或者新的接口和类，但是不要对原有的代码进行更改，不要修改原有的类！

```java
package com.eagles.master;

public class Bird extends Pet {
    public void  eat(){
        System.out.println("鸟喜欢吃虫子");
    }

}
```

```java
package com.eagles.master;

public class Cat extends Pet {
    public  void  eat(){
        System.out.println("猫喜欢吃鱼！");
    }
}
```

```java
package com.eagles.master;

public class Dog extends Pet{
    public  void  eat(){
        System.out.println("狗喜欢吃骨头！");
    }
}
```

```java
package com.eagles.master;

public class Master {
    /*
    只提供一个喂养的方法，参数是一个宠物的父类，多态的最后一个文件的条件：父类的引用接收子类的实例
     */
    public void feed(Pet pet){//Pet pet = new Rabbit/Cat/Dog.....等动物
        pet.eat();      
    }
}
```
