# 为什么要抽象类？

类继承的主要作用在于可以扩展已有类的功能

但是对于继承操作有一个问题，子类可以凭借自己的想法，选择是否重写某一个方法，也就是说父类无法对子类束缚（强制性的你必须覆写某些方法）

抽象类与普通类相比最大的优势在于：可以实现对子类覆写方法的控制，但是在抽象类里面可能依然会保留一些普通方法，而普通方法里面可能会涉及一些安全或者隐私的操作问题！！

#### 抽象类的主要作用在于对子类中的覆写方法进行约定（abstract）

```java
package com.eagles.test;
/*
   1.抽象类无法实例化对象
   2.里面会包含抽象方法
   3.抽象方法只能在抽象类中
   4.抽象类也可以包含普通方法
   5.虽然抽象类不能实例化对象，但是抽象类可以拥有构造函数，构造函数的作用，是用来被子类继承
   6.抽象类是用来被子类继承的
   7.当子类继承抽象类之后，抽象类中的抽象方法是一定要重写的
   8.抽象类没法实例化对象，但是可以基于他的子类实例化对象（多态的引用）
 */
public abstract class MyClass {

    private  String name;   //abstract不可以拿来修饰属性，可以修饰类和方法

    //抽象方法
    public abstract void getMethod();

    //普通方法
    public void getMethod02(){

    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    //无参构造
    public MyClass(){

    }
    //有参构造
    public MyClass(String name){
        this.name = name;
    }
}
class Test09{
    public static void main(String[] args) {

        //   MyClass myClass = new MyClass();

        //通过多态来实例化对象
        MyClass myClass = new MyClasslmpl();//父类的引用去接收子类的实例
        myClass.getMethod(); //调用的子类里面的getMethod方法，输出的是："这是重写之后的方法！"

        MyClass myclass02 = new MyClasslmpl("jack");
        System.out.println(myclass02.getName());

    }
}
```

```java
package com.eagles.test;

public class MyClasslmpl extends  MyClass{

    public MyClasslmpl(String name){
        super(name);       //跳转到父类的name的有参构造，然后间接赋值给MyClass里面的name
    }
    //无参会被默认覆盖掉，所以重新写一下
    public MyClasslmpl(){

    }
    //万能快捷键的使用
    @Override
    public void getMethod() {
        //父类里面的getMethod是一个抽象方法，是没有函数体的，所以继承抽象类之后得对这个方法进行重写
        System.out.println("这是重写之后的方法！");
    }
}
```
