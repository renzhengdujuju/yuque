# 继承

继承的特点：可以扩展已有类的功能

比如：

人的属性：姓名，性别，年龄，身高，体重，学历

学生的属性：名字，学号，年龄，身高，体重，性别，专业，成绩

学生应该包含人的所有特点

如果想要进行代码的重用，必须用到继承的概念

继承的本质：在已有的功能上继续进行功能的扩充

## 子类与父类的关系:

- extends的意思是”扩展“。子类是父类的扩展，使用extends来表示
- java中只有单继承，没有多继承! 一个类只能继承一个父类
- 子类继承了父类，就会拥有父类全部的方法。 ps：private 私有属性及方法无法继承
- 在java中，所有类，都默认直接或间接继承Object类（Ctrl+H 可以查看类关系）
- 被\*\*final\*\*修饰的类，无法继承（final：表示最后的，不可替代的 断子绝孙）

## 继承的优点：

1.提高代码的复用性

2.减少代码的冗余

```java
package com.eagles.pp;

public class Student extends Person {

}
```

```java
package com.eagles.pp;
  public class Person {

     private  String name = "jack";

```

```java

    public class Person {
```

```java

    }
```

```java
package com.eagles.test;

public class Cat extends Animal {
```

```java
package com.eagles.test;

```
