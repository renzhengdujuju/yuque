# 接口：

抽象类与普通类相比最大的优势在于：可以实现对子类覆盖方法的控制，但是在抽象类里面可能依然会保留一些普通方法，而普通方法里面可能会涉及一些安全或者隐私的操作问题。

如果想要对外部隐藏全部细节，则可以通过接口来实现。

接口除了抽象方法和全局变量之外，还可以定义普通方法或静态变量。

# 定义：

接口无法直接实例化对象，所以对于接口的使用原则如下：

- 接口需要被接口实现（implments），一个子类可以实现多个父接口；
- 子类（如果不是抽象类）那么一定要覆写接口之中的全部抽象方法；
- 接口对象可以利用子类对象的向上转型进行实例化

- 接口其实就是一个特殊的抽象类，接口中的方法只能有抽象方法
- 通过**interface**来定义接口
- 接口也是一种引用数据类型，在类加载的时候会生成字节码文件
- 接口中的成员：**抽象方法，常量**
- 由于接口中所有的方法都是抽象的，所以关键字public abstract 是可以省略掉的
- 在接口中是允许有多继承的
- 接口不能实例化对象，它的作用是用来被子类实现的

```java
package com.eagles.interfacetest;

/*
1.接口是一个特殊的抽象类
2.接口不能直接实例化对象，但是可以基于多态的形式创建子类对象
3.接口里面只能拥有常量和抽象方法，不能拥有普通方法
4.接口与类之间 是实现的关系 （implments）一个类可以实现多个接口
5.接口与接口之间是继承关系extends 可以支持多继承
6.类与类之间是继承关系 extends 不可以支持多继承，只能单继承
 */
public interface MyInterface {
    //接口里面可以拥有常量
    public static final String NAME = "jack";
    //抽象方法
    public  abstract  void method();   //public abstract可省
    //省略的抽象方法
    double getSum(double num1,double num2);

}
```

- 接口对象可以利用子类对象的向上转型进行实例化

```java
package com.eagles.interfacetest;
//子类去实现父接口的关键字
public class MyClass implements MyInterface {
    //抽象方法是必须要求重写的
    @Override
    public void method() {
        System.out.println(" this is method !");
    }

    @Override
    public double getSum(double num1, double num2) {
        return num1+num2;
    }
}
```

```java
package com.eagles.interfacetest;

public class InterfaceTest {
    public static void main(String[] args) {

        //基于多态去创建对象(虽然不可以创造接口实例但是可以通过多态去创建对象，
        // 让创建的对象去继承接口，对象重写父类，从而改变父类的值)
        MyInterface myInterface = new MyClass();
        System.out.println(myInterface.getSum(100, 200));
        myInterface.method();
    }
}
```

- 在接口中是允许有多继承的
- public class MyClass implements MyInterface,MyInterface02

```java
package com.eagles.interfacetest;
//子类去实现父接口的关键字
public class MyClass implements MyInterface,MyInterface02 {
    //抽象方法是必须要求重写的
    @Override
    public void method() {
        System.out.println(" this is method !");
    }

    @Override
    public double getSum(double num1, double num2) {
        return num1+num2;
    }

    @Override
    public void method02() {

    }
}
```

# 总结：

1.用interface来定义

2.接口中的所有成员变量都默认是由 public static final 修饰的

3.接口中的所有抽象方法都默认是由 public abstract 修饰的

4.接口中没有构造器（抽象类里面是有构造器的)

5.接口采用多继承机制

6.接口中不能定义构造器！意味着接口不可以实例化

7.接口与接口之间是继承，并且可以多继承
