#### 在前端travel-list页面的删除函数

```html
<script>
//批量删除
        function deleteById(){

            //获取被选中的多选框
            let length = $("[name = 'cks']:checked").length

            if (length > 0){
                if (confirm("是否真的要删除?")){
                    
                  //对所有被选中多选框进行遍历,获得其id的值

                    let ids = "";

                    $("[name = 'cks']:checked").each(function (){
                        ids += ","+$(this).val()
                    })

                    //切割逗号
                    ids = ids.substring(1);

                    $.ajax({
                        url:"http://localhost:8083/web/travel?flag=deleteById",
                        data:{ids:ids},
                        type:"post",
                        success:function (obj){
                            if (obj == "1"){
                                alert('删除成功！')
                                location.href = "http://localhost:8083/web/travel?flag=list";
                            }else if (obj == "2"){
                                alert('删除失败！有问题请联系管理员！')
                            }else if (obj == "3"){
                                alert('不能删除已经报名的线路！')
                            }
                        },
                        dataType:"text"
                    })
                }
            }else {
                alert("请您至少选择一条数据~")
            }
        }
  </script>
```

当勾选的不止一项时，我们需要同时接收好几个线路的sid，所以先利用 let ids = "";先定义一个String的ids字符串将数据全部接收，中间由于是逗号接收的所以得到的字符串应该是“，1,2,3”之类的，所以应该将第一个逗号给切除掉，这里用到的是substring方法，点击事件后会进入flag=deleteById"将数据传入，并且会带入数据ids。页面将会跳转到location.href = "<http://localhost:8083/web/travel?flag=list";>即将删掉的数据将会在数据库消失，重新遍历数据库将不再得到删掉的数据，还对根据不同情况下导致的删除失败写了不同的弹窗内容

#### 1.2.全选全不选的前端

```html
<script>
$(function (){
            //全选全不选
            $("#selectAll").click(function (){
           
                let flag = this.checked;

                $("[name = 'cks']").each(function (){
                    $(this).prop("checked",flag)
                })

            })

        })
  </script>
```

将多选框按钮写一个点击事件，调用this.checked查看是否为选中的状态，是和不是的返回值为布尔类型的，将这个即为flag，将后面遍历到的每一个勾选的属性"checked"改为和多选框的状态是一样的，实现全选全不选的操作，**prop**是设置属性状态的一个关键字。

#### 2.2.创建业务层TravelService

```java
package com.eagles.service;
import com.eagles.pojo.Passenger;
import com.eagles.pojo.Travel;
import java.util.List;

public interface TravelService {
    /**
     * 根据id删除线路
     * @param ids
     * @return
     */
    String deleteById(String ids);

    Travel findPassenger(int tid);
}
```

#### 创建业务层TravelServiceImpl

```java
package com.eagles.service;
import com.eagles.dao.PassengerDao;
import com.eagles.dao.PassengerDaoImpl;
import com.eagles.dao.TravelDao;
import com.eagles.dao.TravelDaoImpl;
import com.eagles.pojo.Passenger;
import com.eagles.pojo.Travel;
import java.text.SimpleDateFormat;
import java.util.Date;
import java.util.List;

public class TravelServiceImpl implements TravelService {

    private TravelDao travelDao = new TravelDaoImpl();

    //业务层处理业务
    @Override
    public String deleteById(String ids) {

        String[] idArray = ids.split(",");

        for (String id : idArray) {
            int num = travelDao.findNumById(Integer.parseInt(id));
            if (num > 0){
                return "3";
            }
        }

        return travelDao.deleteById(ids);
    }
}
```

将传过来的ids进行切割根据","号，得到一个数组，循环数组得到每一组传过来的数字，命名为id，根据findNumById函数查看是否有人报名这个路线，如果遍历到勾选的路线有人参与有将不可以删除，没有人参与将可以删除

**为什么在这里进行判断**

|  |  |  |
| --- | --- | --- |
| **层级** | **职责** | **为什么不能放这里** |
| **Controller (控制器)** | 接收请求、调用 Service、返回结果 | 它只负责“**调用删除**”，不应该知道“**能不能删**”这种业务规则。职责是流程控制，不是业务判断。 |
| **DAO (数据访问)** | 直接操作数据库（增删改查） | DAO 只负责“**物理删除**”这个动作，它不应该关心“**该不该删**”。DAO 应该是通用的、无业务语义的。 |
| **Service (业务)** | **处理业务规则、协调多个 DAO、保证数据一致性** | **正确的位置！** “有报名不能删” 是一个典型的**业务规则**，必须由 Service 层来决策。 |

#### 创建持久层TravelDaoImpl

```java
package com.eagles.dao;
import com.eagles.pojo.Passenger;
import com.eagles.pojo.Travel;
import com.eagles.utils.JDBCUtils;
import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.ArrayList;
import java.util.List;

public class TravelDaoImpl implements TravelDao {

    

    @Override
    public int findNumById(int tid) {

        Connection connection = null;
        PreparedStatement preparedStatement = null;
        ResultSet resultSet = null;

        try {
            connection = JDBCUtils.getConnection();

            String sql = "select num from tb_travel where id = ?";
            preparedStatement = connection.prepareStatement(sql);
            preparedStatement.setInt(1,tid);

            resultSet = preparedStatement.executeQuery();

            if (resultSet != null && resultSet.next()){

                int num = resultSet.getInt("num");
                return num;

            }

        } catch (SQLException e) {
            throw new RuntimeException(e);
        }finally {
            JDBCUtils.close(resultSet,preparedStatement,connection);
        }

        return 0;
    }

    @Override
    public String deleteById(String ids) {

        Connection connection = null;
        PreparedStatement preparedStatement = null;
        ResultSet resultSet = null;

        try {
            connection = JDBCUtils.getConnection();

            String sql = "delete from tb_travel where id in("+ids+")";

            preparedStatement = connection.prepareStatement(sql);

            return preparedStatement.executeUpdate() > 0 ? "1" : "2";

        } catch (SQLException e) {
            throw new RuntimeException(e);
        }finally {
            JDBCUtils.close(null,preparedStatement,connection);
        }
    }
}
```
