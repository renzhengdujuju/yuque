# FTP工作原理以及主被动模式工作原理

FTP 使用两条连接：控制连接和数据连接。控制连接始终是客户端连接服务器的 21 端口。主动模式下，客户端通过 PORT 命令告诉服务器自己的 IP 和端口，服务器从 20 端口主动连接客户端建立数据连接；被动模式下，客户端发送 PASV 命令，服务器开放一个随机高位端口并告知客户端，客户端主动连接该端口建立数据连接。主动模式适合内网或可信环境，被动模式更适合客户端在防火墙或 NAT 后面的场景，因此现在更常用。
